# Electronic -Store — E-commerce full-stack (Node + Express + MongoDB + React/Vite + Tailwind + Framer Motion)

## Requisitos

Node 18+ y MongoDB (local o Atlas).

## Instalación y ejecución local

```bash
# 1) Backend
cd backend && cp .env.example .env
npm install
npm run seed
npm run dev

# 2) Frontend (otra terminal)
cd frontend && npm install
npm run dev
